# CS:R Bot

## Install

Run `py -m pip install -r requirements.txt` to install required modules.

## Run

Run `py main.py` to start the bot.

## .env file template

```yml
SERVER_IP=<csgo server ip>
SERVER_PORTS=<csgo server ports (separated with comma)>

DISCORD_TOKEN=<discord bot token>
RCON_PASS=<rcon password>

GUILD_ID=<discord server id>
QUEUE_CHANNEL_ID=<discord queue text channel id>

DB_HOST=<database ip>
DB_PASS=<database password>
DB_PORT=<database port>
DB_NAME=<database name>
DB_USER=<database user>
```
